# hear-desease-ml_project
🩺 Analyse Prédictive du Risque de Maladie Cardiaque

Ce projet réalise une chaîne complète de traitement en Machine Learning : de l'exploration de données (EDA) à la modélisation par ACP, jusqu'au déploiement d'une application web interactive.
Réduction de Dimension : Application de l'ACP (Analyse en Composantes Principales) pour optimiser les performances.

Optimisation : Recherche d'hyperparamètres via GridSearchCV.
